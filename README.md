# STM32 16×2 LCD Interfacing in 8-Bit Mode

## Overview

This project demonstrates interfacing a 16×2 LCD display with the STM32F446RE microcontroller using 8-bit mode.

In 8-bit mode, all eight LCD data pins (D0–D7) are used to send commands and character data from the STM32 to the LCD.

The project uses GPIO pins to control the LCD and display text on the 16×2 screen.

---

## Components Used

- STM32F446RE Nucleo Board
- 16×2 LCD Display
- Potentiometer
- Jumper Wires
- Breadboard
- Power Supply

---

## Features

- LCD interfacing using 8-bit mode
- LCD initialization
- Sends commands to the LCD
- Sends character data to the LCD
- Displays text on the first line
- Displays text on the second line
- Uses STM32 GPIO pins for LCD control

## Software Used

- STM32CubeIDE
- STM32CubeMX
- Proteus Professional
- C Programming Language
